Приложение создано по заданию пользователя на основе предоставленного дизайна и вымышленных учебных данных.
Официальный логотип вуза, внешние изображения и загружаемые веб-шрифты не используются.
Шрифт: системный стек ОС. Иконки: встроенные SVG из предоставленного дизайн-прототипа.
Сторонних runtime-зависимостей из npm нет. Node.js: MIT и собственные third-party notices; SQLite: public domain.
Для Docker-развертывания используются официальный образ Node.js и Caddy (Apache-2.0).
При проектировании изучены рекомендации https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md; сторонний исполняемый код из этого файла не включен.
