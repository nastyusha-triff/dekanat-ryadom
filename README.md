# Деканат рядом

Учебный портал с кабинетами студента, преподавателя и сотрудника деканата. Здесь доступны расписание, дисциплины, журнал оценок, прогноз результатов и обращения в деканат. Проект: **nastyusha-triff**.

Это конкурсный прототип с вымышленными данными и открытыми демонстрационными аккаунтами. Репозиторий содержит все необходимое для самостоятельного запуска; доступ к авторскому серверу или сервисам ИИ не нужен.

## Быстрый локальный запуск

Требуется **Node.js 24 или новее**. Устанавливать npm-пакеты и отдельный сервер базы данных не нужно: приложение использует встроенный SQLite.

Скачайте репозиторий через **Code → Download ZIP** и распакуйте его либо клонируйте:

```sh
git clone https://github.com/nastyusha-triff/dekanat-ryadom.git
cd dekanat-ryadom
```

В терминале из корня проекта выполните:

```sh
node scripts/seed.mjs
node server/local.mjs
```

Откройте **http://127.0.0.1:8787**. Для остановки нажмите `Ctrl+C` в терминале сервера. На macOS/Linux можно использовать `sh start.command`: скрипт проверит Node.js и занятость порта, подготовит базу и запустит приложение.

Первая команда создает базу и учебные данные. Повторный запуск сохраняет внесенные изменения. Простого `npm start` для самого первого запуска недостаточно: сначала выполните команду заполнения базы выше.

Если порт 8787 занят, задайте другой:

```sh
# macOS / Linux
PORT=8788 node server/local.mjs
```

```powershell
# Windows PowerShell
$env:PORT = "8788"
node server/local.mjs
```

## Аккаунты для проверки

На странице входа нажмите **«Демо»** слева внизу, выберите аккаунт, затем нажмите **«Войти»**. Основные учетные записи:

| Роль | Логин | Пароль |
|---|---|---|
| Студент, 1 курс | `year1_group1` | `Campus26!A1` |
| Студент, 2 курс | `year2_group2` | `Campus26!B2` |
| Студент, 2 курс | `year2_group3` | `Campus26!C3` |
| Преподаватель | `teacher1` | `Teacher26!A1` |
| Деканат | `dekanat` | `Dekanat26!A1` |

Учебный набор содержит 18 студентов, 8 преподавателей, сотрудника деканата и 20 дисциплин. Расписание включает 290 занятий со 2 ноября по 5 декабря 2026 года. Для просмотра этой недели в календаре выберите, например, **23 ноября 2026**. Даты не сдвигаются автоматически: раздел «Сегодня», доступность оценок и запрет изменения прошедших пар зависят от реального времени сервера. Занятия отображаются по московскому времени.

## Что проверить

- **Студент:** расписание и переносы, данные дисциплины и преподавателя, журнал с дедлайнами, калькулятор будущих баллов, создание и уточнение заявки, изменение контактов.
- **Преподаватель:** свои дисциплины, создание и изменение будущих занятий, фильтры по группам, задания, оценки, формулы и экзамены.
- **Деканат:** управление всеми дисциплинами и обработка всех заявок с ответами, статусами и историей.
- **Интерфейс:** светлая и темная темы, календарь на компьютере, карточки на телефоне. Калькулятор не меняет настоящие оценки.

Чат и материалы курса являются внешними ссылками; работа основных функций от них не зависит. При нажатии на внешнюю ссылку открывается соответствующий сторонний сервис.

## Запуск в Docker без установки Node.js

Требуется установленный Docker. Из корня проекта:

```sh
docker build -t dekanat-ryadom .
docker run --rm --name dekanat-ryadom -p 127.0.0.1:8787:8787 -v dekanat_data:/app/data dekanat-ryadom
```

Сайт будет доступен на **http://127.0.0.1:8787**. База создается автоматически и сохраняется в томе `dekanat_data` после остановки контейнера. Первичная загрузка образа Node.js требует интернета.

## Размещение на собственном сервере

Нужны Docker с Compose, домен с DNS-записью на IP сервера и доступные порты 80/443.

1. Скопируйте `.env.example` в `.env` и замените `DOMAIN=portal.example.com` на свой домен без `https://`.
2. Из корня проекта выполните:

```sh
docker compose up -d --build
```

Откройте `https://ваш-домен`. Caddy принимает HTTPS и автоматически получает сертификат, приложение работает во внутренней сети контейнеров. База находится в отдельном томе `portal_data`. Для обычного обновления повторите команду запуска. Команда `docker compose down -v` удаляет тома с данными: для обычной остановки используйте `docker compose down`.

Файл `.env` автоматически используется Docker Compose. При прямом запуске Node.js переменные `PORT`, `HOST`, `DB_PATH`, `PUBLIC_ORIGIN` передаются через окружение. Параметр `PUBLIC_ORIGIN` нужен при собственном HTTPS-прокси; локально его задавать не требуется.

Демонстрационные пароли намеренно публичны, в том числе пароль деканата. Не используйте этот набор аккаунтов для реальных персональных данных.

## Данные и устройство проекта

| Папка | Содержимое |
|---|---|
| `public/` | Интерфейс, стили и иконки |
| `server/` | API, права доступа, формулы и работа с SQLite |
| `drizzle/` | SQL-миграции: создание и обновление таблиц |
| `seed/` | Исходные вымышленные учебные данные |
| `scripts/` | Заполнение базы, запуск и служебные команды |
| `tests/` | Автоматические проверки |

Локальная база создается в `data/portal.sqlite`. Готовая рабочая база, сессии, резервные копии, внутренние промпты и данные авторского хостинга не включены в репозиторий. Новая установка получает учебный набор; изменения пользователей существующего сайта в него не входят. Развертывание на новом сервере само по себе не настраивает внешние резервные копии.

## Проверки

Из корня проекта:

```sh
node --test tests/*.test.mjs
```

Тесты создают временные базы и не затрагивают рабочую. Они проверяют роли и доступ, расписание, формулы и калькулятор, заявки, историю, повторную отправку и сохранность данных. Сторонние пакеты для тестов не нужны.
